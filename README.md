# Mini Backend

The smallest possible backend: a FastAPI server with two JSON endpoints.

## What it does

- `GET /health` → returns `{"status": "ok"}`, confirms the server is alive
- `GET /hello` → returns a JSON greeting message

## Tech stack

- Python 3
- FastAPI
- Uvicorn (ASGI server)

## Run it locally

\`\`\`bash
git clone <your-repo-url>
cd flyrank-mini-backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
\`\`\`

Server runs at `http://127.0.0.1:8000`

## Test it

**curl:**
\`\`\`bash
curl http://127.0.0.1:8000/health
curl http://127.0.0.1:8000/hello
\`\`\`

**Browser:**
- http://127.0.0.1:8000/health
- http://127.0.0.1:8000/hello
- http://127.0.0.1:8000/docs (interactive API docs, auto-generated by FastAPI)
